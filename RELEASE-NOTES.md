# Magicker Mouse 25.0 — App Exceptions

- Disable selected gestures in specific applications using the new App Exceptions menu.
- Disable or enable all listed gestures for an app, or remove its exception.
- Fresh installs now use the creator's current gesture mappings, Lightning Mouse icon, and event-based Auto Reconnect enabled.
- Fresh installs include an Adobe Premiere Pro 2022 exception disabling Two-Finger Hold, preventing accidental Close Window actions while resting two fingers.
- Existing saved settings are preserved. Scrolling and Notification Center behavior are unchanged.

## Install

Download Magicker-Mouse-25.zip, quit the current app, unzip, and replace Magicker Mouse.app in Applications. If requested, grant Accessibility access again. Requires Apple silicon and macOS 15 or later. The app is ad hoc signed and is not notarized.
